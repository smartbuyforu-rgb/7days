# 7days

THANKS 7DAYS 상품 카탈로그 자동 생성용 저장소입니다.

## 사용 방법

1. 이 저장소에 `thanks_7days_catalog_generator.py`와 `.github/workflows/update.yml`을 업로드합니다.
2. GitHub 저장소의 `Actions` 탭에서 workflow를 허용합니다.
3. `Update Thanks 7DAYS Catalog` workflow를 수동 실행하거나 10분마다 자동 실행되도록 둡니다.
4. 실행 후 `index.html`이 생성됩니다.
5. Settings → Pages → Deploy from a branch → `main` / `/root`로 설정합니다.
